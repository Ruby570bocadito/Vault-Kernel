### 3. Dead code del dispatcher Go (hallazgo 5 del Director)

- `case "version": printVersion(); return nil` era INALCANZABLE:
  `version`/`-v`/`--version` se interceptan y retornan ANTES de
  `openDevice()` desde la reorganización v3.6 — ningún camino desde
  `run()` alcanza el case. Eliminado; el handler pre-dispositivo
  lleva una NOTE que documenta la eliminación y apunta al informe de
  esta ronda. `printVersion` sigue vivo (el handler lo usa).
- Verificación: `go vet` limpio, 39/39 tests Go, build OK, y el
  binario smoke responde igual a `version`/`-v`/`--version`.
- El único `case "version"` restante en el fichero es el del parser
  `parseModinfo` (código nuevo de esta ronda, legítimo).
